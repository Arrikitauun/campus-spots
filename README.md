# Campus Spots

A small pocket guide to Kraków for students, built with React Native and Expo during the Mobile Application Development labs at Politechnika Krakowska.

## How to start

1. Install the dependencies:

   npm install

2. Start the development server:

   npx expo start

3. Scan the QR code with Expo Go on your phone (Android: inside Expo Go, iPhone: with the Camera app).
   If the phone cannot connect on the same Wi-Fi, use `npx expo start --tunnel`.
